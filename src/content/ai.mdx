## Local development

Use a supported Node.js installation and your own development credentials.

```bash
git clone https://github.com/GothwadTech/ai.git
cd ai
npm install
```

The upstream README instructs setting `GEMINI_API_KEY` in `.env.local`, then running:

```bash
npm run dev
```

Do not commit `.env.local`. Before deployment, inspect how the current implementation uses the key. A local environment file does not guarantee a value remains server-side when bundled by a frontend build tool.

## Before a public deployment

1. Review the Vite and server configuration for environment-variable exposure.
2. Ensure provider credentials stay on a protected server or Worker.
3. Apply appropriate authentication, request limits, and usage controls.
4. Test with a separate development key.
5. Document the verified deployment architecture before publishing integration examples.
