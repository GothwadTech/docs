## Overview

Gothwad Browser focuses on desktop-style browsing across Android phones, tablets, and TVs. The source README also describes desktop installation packages. This guide summarizes the product; it does not verify the availability of every release artifact.

The documented Android experience includes remote and keyboard navigation, a file manager, notes, clipboard tools, and ad and tracker protection.

## Installation workflow

1. Open the product's [repository README](https://github.com/GothwadTech/browser#readme).
2. Follow the official store or download link appropriate to your device.
3. Verify the publisher and platform before installing a package.
4. On Android, prefer the official store path. Only enable sideloading for an installer you trust, and turn it off afterward.
5. Test navigation with the actual remote, keyboard, or touch input used on your device.

Do not assume a desktop package exists just because its format is listed in a README; check the release assets linked by the maintainer.

## Input and device testing

For a TV deployment, verify D-pad focus, back-button behavior, scrolling, text input, and tab navigation. For phones and tablets, verify touch targets, orientation changes, and download handling. Browser capability depends on the target platform and rendering engine.

## Reporting an issue

Use the repository's issue tracker. Include the device model, Android or desktop OS version, app version, input method, reproduction steps, and the expected result. Redact browsing history, account details, and private URLs.
